# BrAInChain

Autonomous cryptocurrency trading intelligence platform built on top of Freqtrade, with a roadmap toward ML/RL decisioning, on-chain intelligence, new-token discovery, security analysis and autonomous risk-controlled execution.

## Current phase

**Phase 0 — Foundation**

- Freqtrade upstream baseline
- OKX Spot as the initial market venue
- Dry-run first
- Reproducible development environment
- Automated validation through GitHub Actions

## Safety status

This project is **not authorized for real-money trading**. Production trading is intentionally disabled while the architecture, data pipeline, models and risk controls are being developed and validated.

## Roadmap

1. Freqtrade baseline and CI
2. OKX Spot dry-run
3. Backtesting and data pipeline
4. FreqAI / ML baseline
5. Regime detection
6. Risk engine
7. On-chain intelligence
8. New-token discovery and security gates
9. Social/sentiment intelligence
10. Multi-model decision engine
11. RL experimentation
12. Controlled OKX Demo execution adapter
13. Multi-exchange / DEX execution
14. Graduated autonomy

See `docs/BRaINCHAIN-ARCHITECTURE.md` for the architectural boundary and safety rules.
